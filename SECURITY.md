## Reporting a Vulnerability

The PlasticWatch maintainers take security seriously. If you discover a security vulnerability or sensitive data exposure issue, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Email the maintainer directly at `ayushphalak5@gmail.com` with the subject line `[SECURITY] PlasticWatch Vulnerability Report`.
3. Provide detailed steps to reproduce the issue, along with any relevant proof-of-concept logs or payloads.

We will acknowledge receipt within 48 hours and work with you to triage, verify, and address the issue promptly before public disclosure.
